# 간단한 시작 가이드

## 1. 백엔드 설정 (한 번만)

```bash
cd backend
python -m venv venv
venv\Scripts\activate  # Windows
pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser  # 관리자 계정 만들기 (선택사항)
```

## 2. 백엔드 실행

```bash
cd backend
venv\Scripts\activate
python manage.py runserver
```

서버가 http://127.0.0.1:8000 에서 실행됩니다.

## 3. 프론트엔드 실행

```bash
cd frontend
npm install
npm start
```

브라우저에서 http://localhost:3000 이 자동으로 열립니다.

## API 엔드포인트

- `GET /api/posts/` - 게시물 목록
- `POST /api/posts/` - 게시물 작성
- `POST /api/posts/{id}/add_comment/` - 댓글 추가
- `POST /api/posts/{id}/increment_views/` - 조회수 증가
- `GET /api/posts/stats/` - 통계
